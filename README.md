# 《家》话语研究工作台 — GitHub Pages 版

这是现有研究工作台的静态迁移版本，适用于 GitHub Pages。

## 保留的功能

- 《家》全文语料与章节浏览
- 关键词词频与章节分布
- 关键词检索和语境查看
- 人工编码表单
- 当前 24 条“反抗”编码
- CSV 导入与导出
- 浏览器本机自动保存

## 与原在线版的区别

GitHub Pages 不运行服务器端数据库。编辑内容会保存在当前浏览器中，不会自动同步到其他设备。请阶段性导出 CSV 备份。

`data/jia-coded-occurrences.csv` 是迁移时的在线数据备份。

## 发布

本项目可直接通过 GitHub Pages 发布：在仓库 Settings → Pages 中选择
“Deploy from a branch”，分支选择 `main`，目录选择 `/ (root)`。

发布地址：<https://amyc19.github.io/jia-discourse-workbench/>
